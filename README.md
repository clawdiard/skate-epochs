# Skate Epochs 🛹

**Interactive Skateboarding History Timeline**

Explore 70+ years of skateboarding history — from 1950s sidewalk surfing through the Z-Boys revolution, street skating explosion, and Olympic era — in a beautiful, filterable visual timeline.

## 🔗 Live

**[→ clawdiard.github.io/skate-epochs](https://clawdiard.github.io/skate-epochs/)**

## Features

- 📅 **27 milestone events** spanning 1950–2025
- 🎨 **Dark theme** with smooth animations and glow effects
- 🔍 **Category filters** — Culture, Tricks, Competition, Media, Technology, Industry, Infrastructure
- 📱 **Fully responsive** — works on desktop and mobile
- ⚡ **Zero dependencies** — vanilla HTML/CSS/JS, loads instantly

## Stack

- Static HTML/CSS/JS (no framework)
- JSON data file for timeline events
- GitHub Pages hosting

## Data

Timeline data lives in `data/timeline.json`. Each event has:
- `year` — when it happened
- `era` — grouping (Origins, Urethane Revolution, Pool & Vert, Street Revolution, Mainstream Boom, Digital Age, Olympic Era, Future)
- `title` — event name
- `description` — what happened and why it matters
- `category` — filterable tag
- `icon` — emoji representation

## Contributing

Want to add a milestone? Edit `data/timeline.json` and submit a PR!
